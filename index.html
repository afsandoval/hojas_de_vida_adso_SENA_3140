Directorio de Aprendices

Actividad práctica de Control de Versiones con Git y Visual Studio Code. Cada aprendiz edita su propia tarjeta y construye su Hoja de Vida como parte del proceso de aprendizaje.

¿Qué debo hacer en esta actividad?

  1. Clona este repositorio en tu equipo usando git clone.
  2. Abre la carpeta del proyecto con Visual Studio Code.
  3. Busca en este archivo index.html la tarjeta con tu número asignado por el instructor.
  4. Reemplaza los comentarios <!-- EDITA AQUÍ ... --> con tu foto, nombre y biografía corta.
  5. Crea tu propio archivo HV_nombre_aprendiz.html (puedes copiar HV_ejemplo.html como base) con tu Hoja de Vida completa.
  6. Actualiza el enlace del botón "Ver Hoja de Vida Completa" de tu tarjeta para que apunte a tu archivo.
  7. Guarda los cambios con git add, git commit y git push.
